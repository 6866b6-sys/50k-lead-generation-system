🎯 获客系统 (Lark/飞书版)

    全自动 B2B 获客引擎：集成 Apollo.io、Google 搜索、LinkedIn 爬虫及 AI 自动评估，基于飞书多维表格（Lark Bitable）构建。

🎯 项目概述

获客系统 (Lead Generation System) 是一款企业级自动化工具，将多种获客渠道和信息增强手段整合进一个智能工作流中。系统从 Apollo.io 抓取线索，通过 Google 搜索挖掘潜在客户，利用 LinkedIn 数据完善画像，并最终通过 AI 根据你的理想客户画像 (ICP) 进行自动评分。
解决的痛点

传统的 B2B 获客需要数天的手动研究。本系统通过 飞书多维表格 (Lark Bitable)，在数小时内即可自动处理数千条线索，并确保数据质量的一致性和 AI 评分的客观性。
✨ 核心功能
🔄 多源自动获客

    Apollo.io 搜索结果自动抓取

    结合 Google 搜索挖掘 LinkedIn 个人资料

    双通道获客模式，确保市场覆盖率最大化

🤖 AI 驱动的线索评估

    直接通过飞书调用 Google Gemini 模型分析每一条线索

    根据 ICP 匹配度进行 0-10 分自动评分

    自动分析公司官网内容，精准识别业务性质

📊 智能数据管理

    预设结构化的 飞书多维表格 (Lark Bitable) 数据库

    基于“营销活动 (Campaign)”的线索组织方式

    通过飞书自动化实现任务状态实时追踪

🔄 自动化工作流
1️⃣ 工作流：ScrapeApollo (Apollo 抓取)

流程： 从飞书读取 Apollo 活动配置，调用爬虫脚本，并将结果插入飞书 Apollo 线索表。
2️⃣ 工作流：EnrichProfiles (画像增强)

流程： 从飞书读取基础线索，调用 LinkedIn 爬虫，自动回写 25+ 项深度字段至飞书记录。
3️⃣ 工作流：QualifyLeads (AI 评估)

流程： 从飞书获取线索，通过 Tavily 提取官网内容，由 Google Gemini 生成评分并更新飞书评分字段。
🛠️ 技术栈
类别	技术	用途
自动化	n8n	工作流编排与逻辑调度
数据库	飞书多维表格 (Lark Bitable)	线索存储与营销活动管理
数据抓取	Apify	Apollo 与 LinkedIn 深度数据采集
搜索	Serper.dev	通过 Google 搜索 API 发现潜在客户
AI 评估	Google Gemini	基于 ICP 的线索自动打分
🚀 安装步骤
第一步：配置飞书多维表格

    创建一个新的多维表格，命名为“自动化获客系统”。

    创建以下数据表：Apollo 营销活动、Apollo 线索、Google 搜索活动、Google 搜索线索、聚合邮件库。

第二步：配置 API 密钥

    从多维表格的 URL 中获取 App Token 和 Table ID。

    在 n8n 中配置飞书/Lark 自建应用的凭证（Client ID, Client Secret）。

第三步：设置飞书自动化

在飞书多维表格中设置“发送 Webhook”自动化：

    触发条件： 当“开始执行”复选框被勾选时。

    动作： 触发 n8n Webhook URL 并传递 recordId。

📖 使用指南

    创建活动： 在飞书活动表中填入 Apollo 搜索链接或 ICP 搜索准则。

    启动： 在飞书中勾选“开始执行”。

    查看结果： 线索将实时同步。高分潜在客户 (8-10 分) 将在你的飞书视图中通过筛选器或颜色高亮自动置顶。
